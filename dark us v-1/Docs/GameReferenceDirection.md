# Game Reference Direction

`dark us`의 개발 방향을 잡을 때 참고할 기준 게임과 적용 원칙입니다.

## 기준 레퍼런스

- **Deceit 2**: 1인칭 공포, 소셜 디덕션, 라운드 긴장감.
- **Among Us / Goose Goose Duck**: 방, 역할, 임무, 반복 플레이 루프.
- **First Class Trouble / Project Winter**: 협동과 배신의 심리전, 대기방과 라운드 흐름.
- **Unfortunate Spacemen / SCP: Secret Laboratory**: 시설형 공포, 역할별 목표, 혼란스러운 멀티플레이 상황.
- **Lethal Company**: 친구끼리 웃기면서 무서운 1인칭 협동 공포 감각, 음성/상황 반응 중심 플레이.

## 적용 방향

- 라운드 루프는 **Among Us식으로 단순하고 반복 가능하게** 만든다.
- 분위기와 공포 연출은 **Deceit 2 / SCP 계열처럼 어둡게** 잡는다.
- 친구끼리 플레이하는 감각은 **Lethal Company처럼 음성, 돌발 상황, 반응 중심**으로 살린다.
- 임무와 배신 구조는 **Project Winter / First Class Trouble처럼 자연스럽게 의심이 생기도록** 설계한다.
- UI, 로비, 설정, 방 흐름은 **반복 플레이에 걸림돌이 없도록 안정성 우선**으로 만든다.

## 기능 판단 기준

새 기능을 넣거나 기존 기능을 고칠 때 아래 질문을 기준으로 본다.

- 역할 추리와 의심을 더 잘 만들 수 있는가?
- 공포와 긴장감을 해치지 않는가?
- 친구끼리 반복 플레이했을 때 재미가 유지되는가?
- 대기방, 설정, 라운드 시작/종료 흐름을 더 복잡하게 만들지 않는가?
- 멀티플레이 안정성을 떨어뜨릴 위험은 없는가?
