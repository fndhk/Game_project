# Release Readiness Checklist

현재 기준으로 출시 전 반드시 안정화해야 할 항목입니다.

## 멀티플레이 안정성

- 방 만들기, 공개방, 친구 참가가 반복 사용되어도 Photon 상태가 꼬이지 않아야 한다.
- 게임 종료 후 메인 화면 또는 대기방으로 돌아왔을 때 버튼 입력, 준비, 시작, 참가가 정상 동작해야 한다.
- 씬 전환, EventSystem, Photon 룸/플레이어 상태 정리를 우선 점검한다.

## 처음부터 끝까지 반복 플레이 테스트

- `메인 화면 -> 방 생성/참가 -> 대기방 -> 게임 시작 -> 게임 종료 -> 다시 대기방/메인 -> 재시작` 흐름을 반복 테스트한다.
- 최소 10회 이상 반복해도 클릭 불가, 준비 불가, 시작 불가, 씬 로드 실패가 없어야 한다.

## 빌드 검증

- 에디터 기준이 아니라 실제 Windows 빌드에서 확인한다.
- Build Profile, 빌드 씬 등록, Resources 로드, Photon 설정, 해상도별 UI를 검증한다.

## 게임 목표/재미 보강

- 임무 수, 라운드 긴장감, 도플갱어/시민 밸런스, 승리 조건을 더 명확하게 다듬는다.
- 아이템이 각 역할과 라운드 흐름에서 의미 있게 쓰이는지 확인한다.

## UI/설정 완성도

- 설정, ESC 메뉴, 대기방, 방 찾기, 게임 종료 후 흐름을 안정화한다.
- 클릭 안 됨, ESC 안 됨, 설정 다시 안 열림 같은 문제는 출시 전 0개에 가깝게 줄인다.

## 사운드/아트 정리

- BGM/SFX 볼륨 밸런스와 반복 피로감을 확인한다.
- 사용 에셋의 라이선스와 출처를 출시 전에 정리한다.

## 최적화 실측

- 실제 빌드에서 FPS, 메모리, 로딩 시간, 네트워크 전송량을 측정한다.
- 용량 정리만으로 끝내지 말고 프로파일링 기준으로 병목을 확인한다.

## 출시 기본 요소

- 아이콘, 게임 이름, 버전 표기, 옵션 저장, 크래시 대응을 준비한다.
- 튜토리얼/조작 안내, 종료 처리, 해상도 대응, 한국어/영어 텍스트 정리를 마무리한다.
