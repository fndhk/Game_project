Scan Items Pack

Files
- Fuse.obj / Fuse.mtl
- Generator.obj / Generator.mtl
- ExitGate.obj / ExitGate.mtl

Unity import
1. Drag the OBJ and MTL files into your Assets folder.
2. Unity will import them as meshes.
3. Create prefabs from the imported models.
4. Add one root collider only on the prefab root.
5. For gameplay:
   - Fuse -> pickup interactable
   - Generator -> repair/activate interactable
   - ExitGate -> escape interactable

Notes
- These are prototype silhouette-first models for scan readability.
- They are intentionally simple and low-poly.
- Pivot is placed near the base center for easy placement.
